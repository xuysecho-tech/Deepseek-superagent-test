## Todo 页面

仓库根目录是一个零依赖的待办清单页面，直接用浏览器打开 `index.html` 即可使用，无需安装或构建。

功能：

- 添加待办：输入后按 Enter 或点击「添加」
- 双击标题或点击铅笔图标编辑待办，Enter 保存、Esc 取消
- 勾选完成、删除单条待办
- 按「全部 / 待完成 / 已完成」筛选，一键清除已完成
- 搜索待办：点击搜索图标或按 `/`，Esc 关闭
- 拖动排序：拖动手柄上下移动，聚焦手柄后也可用 ↑ ↓ 调整
- 删除与清除已完成支持撤销：6 秒内点击「撤销」或按 Ctrl/Cmd + Z
- 深色 / 浅色主题：默认跟随系统偏好，切换后会记住选择
- 完成进度环与数量统计
- 待办数据保存在浏览器 localStorage，刷新后不丢失
- 响应式布局，适配桌面与手机
