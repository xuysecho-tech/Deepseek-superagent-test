## Todo 页面

仓库根目录是一个零依赖的待办系统，直接用浏览器打开 `index.html` 即可使用，无需安装或构建。

布局与视图：

- 左侧边栏：账户信息、今天、明天、未来七天、全部待办、已逾期、已完成，并显示各视图数量与今日进度
- 中间主界面：当前视图的任务列表；「今天」视图下方展示今日已完成
- 顶部「添加」按钮打开任务弹窗，可填写任务名称、备注、日期与优先级（低 / 中 / 高）

功能：

- 添加任务；点击任务标题可再次编辑；勾选完成、删除任务
- 日期支持快捷「今天 / 明天 / 清除」，逾期任务以红色标识
- 任务按日期与优先级排序
- 搜索当前列表：按 `/` 聚焦搜索框，Esc 清除
- 删除与清除已完成支持撤销：6 秒内点击「撤销」或按 Ctrl/Cmd + Z
- 深色 / 浅色主题：默认跟随系统偏好，切换后记住选择
- 数据保存在浏览器 localStorage，刷新后不丢失
- 响应式布局：窄屏下侧边栏变为顶部导航，任务弹窗自适应
